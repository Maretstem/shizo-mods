# SHIZOSTAN — сборка сервера

Отсюда ShizoLauncher берёт моды. `pack.json` — список файлов с версией сборки, `files/mods/` — сами моды.

## Панель для админов — по ссылке

**<https://maretstem.github.io/shizo-mods/admin/>** — работает в браузере с любого компьютера, ставить ничего не нужно.

Как дать доступ новому админу:

1. Владелец репозитория открывает на GitHub **Settings → Collaborators → Add people** и добавляет аккаунт админа.
2. Админ принимает приглашение из письма.
3. Админ открывает панель, по ссылке в блоке «Вход для админов» создаёт ключ (внизу страницы GitHub кнопка **Generate token**) и вставляет его в панель. Ключ хранится только в его браузере.

Дальше как обычно: перетащить новые , удалить лишние, проверить номер версии, написать «что нового» и нажать **«Опубликовать»**.

Что важно знать:

- **Ключ — это пароль.** Он даёт право изменять публичные репозитории админа. Никому не пересылать. Если ключ утёк — отозвать на <https://github.com/settings/tokens>.
- **Забрать доступ у админа:** удалить его в Settings → Collaborators. Его ключ сразу перестанет работать для этого репозитория.
- **Двое публикуют одновременно:** второй получит ошибку «кто-то опубликовал раньше» — нужно обновить страницу и повторить.
- Без ключа панель открывается только для просмотра.

## Панель на своём компьютере (для владельца)

На рабочем столе лежит ярлык **«Сборка SHIZOSTAN»**. Он открывает страничку в браузере:

1. Перетащи новые `.jar` в рамку (или удали лишние кнопкой «Удалить»). Если мод обновился, панель пометит обе версии «две версии?» — старую удали.
2. Проверь номер версии (панель сама предлагает следующий) и напиши, что нового.
3. Нажми **«Опубликовать»**.

Панель сама забирает то, что было загружено через сайт GitHub, пересчитывает `pack.json` и отправляет всё куда нужно. Наверху видно, какая версия сейчас у игроков; новая появляется через 1–6 минут.

Пока панель открыта, на панели задач висит свёрнутое чёрное окно — это она и есть. Закроешь вкладку или это окно — панель выключится.

Если ярлык потерялся, запусти в папке `shizo-launcher`:

```bash
node --use-env-proxy tools/pack-panel.mjs
```

## Как обновить сборку вручную

Нужно три вещи: поменять моды, пересобрать список, отправить на GitHub. Занимает пару минут.

> **Важно: меняй моды только в папке на компьютере, а не через сайт GitHub.**
> Кнопки «Add file» и «Delete» на сайте кладут файл в репозиторий, но не обновляют `pack.json`, поэтому игроки обновление не получат, а следующий `git push` с компьютера будет отклонён.
> Если всё же загрузил что-то через сайт — выполни в папке `shizostan-pack` команду `git pull`, а потом шаги 2 и 3.

### 1. Поменяй моды

Открой папку `shizostan-pack\files\mods` и сделай что нужно:

- **обновить мод** — удали старый файл, положи новый (например, убрал `binary-barrier-1.2.0.jar`, положил `binary-barrier-1.4.0.jar`);
- **добавить мод** — просто положи `.jar`;
- **убрать мод** — удали файл.

Старую версию мода обязательно удаляй: два файла одного мода ломают запуск игры.

### 2. Пересобери список

Открой терминал в папке `shizo-launcher` (в проводнике: зайди в папку, в адресной строке напечатай `cmd` и нажми Enter) и выполни, подставив свой номер версии и описание:

```bash
node tools/make-pack.mjs ../shizostan-pack --version 1.0.2 --changelog "Что изменилось в этой версии"
```

- `--version` — каждый раз **новый** номер (1.0.2, 1.0.3, …). Лаунчер понимает, что вышло обновление, только когда номер изменился.
- `--changelog` — текст, который игроки увидят в лаунчере в блоке «Что нового».

Команда ответит строкой вида `pack.json: версия 1.0.2, файлов 89, 134.5 МБ`.

### 3. Отправь на GitHub

Открой терминал уже в папке `shizostan-pack` и выполни по очереди:

```bash
git add -A
```
```bash
git commit -m "Сборка 1.0.2"
```
```bash
git push
```

Через одну-две минуты обновление появится у всех: при следующем запуске лаунчер покажет «Обновить и играть», докачает только изменённые моды и сам удалит убранные.

### Проверить, что обновление вышло

Открой в браузере <https://maretstem.github.io/shizo-mods/pack.json> — в начале должно стоять твоё новое значение `"version"`. Если там ещё старое, подожди минуту и обнови страницу.

## Частые вопросы

**Забыл поменять номер версии.** Игроки обновление не увидят. Запусти шаги 2 и 3 ещё раз с новым номером.

**`git push` пишет `rejected ... fetch first`.** На GitHub есть изменения, которых нет на компьютере (обычно — загрузка через сайт). Выполни `git pull`, затем заново шаги 2 и 3.

**`git commit` пишет `unable to auto-detect email address`.** В этой папке имя для коммитов уже настроено. Если ошибка появилась в другой копии папки, выполни один раз `git config user.name "Maretstem"` и `git config user.email "Maretstem@users.noreply.github.com"`.

**`git push` выдаёт ошибку сети.** GitHub на этом компьютере открывается только через прокси — проверь, что он включён, и повтори команду.

**Файл больше 100 МБ.** GitHub такой не примет. Такой мод придётся раздавать отдельно.

**Что лаунчер не трогает у игроков.** Моды, которые игрок добавил сам, его миры, настройки и конфиги. Удаляются только те файлы, которые раньше были в сборке, а теперь убраны.

**Конфиги.** Сейчас в сборке только моды. Если захочешь раздавать и конфиги — положи их в `files/config/`. Они ставятся один раз и потом не перезаписываются, чтобы не сбивать игрокам их настройки.

**Репозиторий публичный.** Всё, что лежит в `files/`, может скачать любой человек по ссылке. Не клади сюда моды, авторы которых запрещают перевыкладывать файлы.
