Сборка SHIZOSTAN

Вход для админов

  1. Попроси владельца добавить твой аккаунт GitHub в репозиторий и прими приглашение из письма.
  2. Открой страницу создания ключа, внизу нажми Generate token и скопируй ключ (он начинается на ghp_).
  3. Вставь ключ сюда. Он хранится только в этом браузере.

Ключ даёт право изменять твои публичные репозитории — никому его не показывай. Отозвать можно на той же странице GitHub.
